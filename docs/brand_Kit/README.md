# Taply — Brand Kit

Este paquete reúne:
- Variantes raster y vectoriales del logo e isotipo.
- Recursos visuales separados por categoría para la landing.
- Cinco composiciones conceptuales previas y el styleboard completo.
- Guía de identidad con paleta, tipografía y recomendaciones de uso.

Empieza por `04_Guia_de_Marca/guia-de-identidad-visual.md`.
Los SVG son editables. Los recortes individuales proceden del styleboard y sirven como base visual; no todos equivalen a una exportación original aislada de alta resolución.
